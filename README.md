## Entry

My fridge lights up at 3am like it's happy to see me, but we both know it's just judging the same leftovers.

## Why this line

This line is unmistakably about a fridge and finds two specific details worth mocking: the theatrical 3am light and the same tired leftovers waiting inside. The twist flips warmth into judgment — the fridge seems glad to see you, then immediately becomes the quiet critic of your midnight habits. It reads cleanly out loud with a natural setup-and-punch rhythm, and it needs no context: anyone who has ever opened a fridge half-asleep instantly gets the joke.

## Verification

Run with Node (stdlib only):

```sh
MAKEFUN_OUTPUT_DIR=output node main.ts
cat output/entry.txt
```

`main.ts` writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt`, validates the bounty gate (single line, at most 200 characters), then reads the file back and verifies it byte-for-byte before logging the result.
